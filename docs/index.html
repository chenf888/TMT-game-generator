tmt-game-generator is an agent skill. Say “make me an incremental game about X” and your agent runs the full measured pipeline — interview, data-driven design, scaffold, layer-by-layer generation, 72 static rules, a load-time smoke test, a pacing simulation, browser verification — and hands you a game that opens and plays, balanced, with a clean console.

tmt-game-generator 是一个 Agent Skill：对它说一句「给我做一个关于 X 的增量游戏」，你的 agent 就走完一条带实测的流水线——采访、数据设计、脚手架、逐层生成、72 条静态规则、载入冒烟、平衡实测、浏览器实测——交付一个打开即玩、曲线平衡、控制台零报错的游戏。

It doesn't guess numbers. It counts them.它不猜数字。它数数字。

The wiring rule: most real upgrades carry their power not in effect() but in a branch of their layer's gainMult(). So the brief must name a consumer for every upgrade — an effect nobody consumes gets caught by the checker.

接线规则：一多半真实升级的威力不写在 effect() 里，而写在所在层 gainMult() 的分支里。所以设计书必须给每个升级指名消费者——没有消费者的效果，会被静态检查揪出来。

The simulation is a floor, not a forecast: on one build a human ran 2.5 hours while the sim ran 0.62 (×4); on another, 99.8 hours matched the target. If the floor already misses the target, the target is missed — read the early timeline first, calibrate the total second.

模拟是下界，不是预测：某局人类实玩 2.5 小时、模拟 0.62 小时（×4）；另一局 99.8 小时与目标吻合。下界已经错过目标，目标就是错的——所以先读时间线，再校准总数。

The pipeline: any stage can send the brief back流水线：每一道都可能把设计书打回去

When a check fails, fix the table, not the code — the brief is the contract, the code is its execution.

检查不过关时，修的是表格，不是代码——设计书是契约，代码是它的执行。

Interview采访

At most 7 structured questions: how the theme decides the structure, the scale blueprint, natural ceilings, pacing and interactivity, automation tolerance, language. A final question locks the game type — classify.js proposes, you confirm.最多 7 个结构化问题：主题如何决定结构、规模蓝图、自然上限、节奏与互动、自动化容忍、语言。最后一步锁定游戏类型——classify.js 提议，由你确认。

Type first, then code先定类型，再写代码

The interview's final step locks the game type — orthogonal to the scale blueprint. The type decides which components are mandatory, which are exempt, and which acceptance rules apply.

采访的最后一步锁定游戏类型。类型与规模蓝图正交：它决定哪些组件强制、哪些被豁免、哪些验收规则生效。

On top of the type, 6 modifiers can stack (themable challenges, offline progress and friends). A modifier whose hard dependency is unmet is downgraded with a written reason, never silently dropped.

在类型之上还可以叠加 6 个修饰符（主题化挑战、离线进度等）。硬依赖不满足时，修饰符会被降级并写明理由，绝不静默丢弃。

构建产物就是 skill 本体：拷进你的工具的 skills 目录，新开会话即可触发。

Requires Node.js ≥ 18; the five scripts have zero npm dependencies. To play the result, any static file server (npx http-server <folder>).

要求 Node.js ≥ 18；五个脚本零 npm 依赖。玩生成结果需要一个静态文件服务器（npx http-server <目录>）。
